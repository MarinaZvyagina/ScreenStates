# Security Policy

## Supported Versions

ScreenStates is a small, dependency-free client-side UI library — there's
no server component and no persisted or transmitted secrets. Only the
latest released version is supported; please upgrade before reporting an
issue that might already be fixed.

## Reporting a Vulnerability

Please **don't** open a public GitHub issue for a suspected security
vulnerability. Instead:

- Preferred: use GitHub's [private vulnerability reporting](https://github.com/MarinaZvyagina/ScreenStates/security/advisories/new)
  for this repository.
- Alternatively, email zvyagina.marina@gmail.com with a description of the
  issue and, if possible, steps to reproduce it.

You should expect an initial response within a few days. Since this is a
small, actively-maintained open-source project without a formal bug-bounty
program, there's no monetary reward, but you'll be credited in the fix's
release notes unless you'd prefer otherwise.
